# 🍳 Cook Again 料理筆記

記錄每一次做菜：食譜、烹煮步驟（可附過程照片）、成品照、評分、**該怎麼改進**。
下次再做同一道菜時，自動提醒你上次的改進建議，並可一鍵帶入上次的食譜。

- 支援各種料理：中式、西式、日式、韓式、東南亞、甜點、烘焙、飲品…
- 資料存在**你自己的 Google 試算表**，照片存在**你自己的 Google 雲端硬碟**
- 自動產生文字版食譜，可複製分享
- 手機優先設計、深色模式、草稿自動保存、離線暫存後再上傳
- 全部免費，不需要伺服器

👉 **安裝教學（手把手）：[docs/SETUP.md](docs/SETUP.md)**
