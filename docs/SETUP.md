# 🍳 Cook Again 安裝教學（手把手版）

整個系統由三個部分組成，全部免費：

```
 ┌──────────────┐   上傳紀錄/照片    ┌──────────────────┐   寫入   ┌────────────────────┐
 │ 網頁 App      │ ───────────────▶ │ Google Apps Script │ ──────▶ │ Google 試算表（文字）│
 │ (手機/電腦瀏覽)│ ◀─────────────── │ （你的小型後端）      │ ──────▶ │ Google 雲端硬碟（照片）│
 └──────────────┘   讀取紀錄        └──────────────────┘          └────────────────────┘
   放在 GitHub Pages                    綁在試算表裡
```

- **網頁 App**（`index.html`、`app.js`、`style.css`）：你在手機上填寫、拍照、看紀錄的介面。
- **Google Apps Script**（`apps-script/Code.gs`）：Google 提供的免費小程式，負責把資料寫進試算表、把照片存進雲端硬碟。
- **Google 試算表 + 雲端硬碟**：真正存放資料的地方，你隨時可以直接打開來看。

> 💡 為什麼用「Google 試算表」而不是「Google 表單」？Google 表單無法做到「每個步驟各自附照片」、「再做一次時帶入上次食譜」這類功能。其實 Google 表單收到的資料最後也是存進試算表，所以我們直接寫進試算表，效果一樣、彈性更大。

預計時間：**約 15 分鐘**。請照順序做。

---

## 第 1 部分：建立 Google 試算表和 Apps Script（約 8 分鐘）

### 步驟 1-1　建立試算表
1. 用電腦打開 <https://sheets.new>（會直接建立一份新的空白試算表）。
2. 點左上角「未命名的試算表」，改名為 **`Cook Again 料理紀錄`**。

### 步驟 1-2　打開 Apps Script 編輯器
1. 在試算表上方選單點 **「擴充功能」→「Apps Script」**。
2. 會開啟一個新分頁，裡面有一個叫 `程式碼.gs`（或 `Code.gs`）的檔案，內容是：
   ```js
   function myFunction() {
   }
   ```

> ⚠️ 一定要從試算表的「擴充功能」打開，程式才會知道要寫進哪一份試算表。

### 步驟 1-3　貼上程式碼
1. 在 GitHub 打開本專案的 [`apps-script/Code.gs`](../apps-script/Code.gs)，點右上角的「複製」圖示（Copy raw file）。
2. 回到 Apps Script 編輯器，**把原本的內容全部刪掉**（Ctrl+A 再 Delete；Mac 用 ⌘+A），然後貼上。

### 步驟 1-4　設定你自己的密碼 🔑
找到程式最上面這一行：
```js
const API_TOKEN = 'change-me-to-your-own-secret';
```
把 `change-me-to-your-own-secret` 改成你自己想的密碼，例如：
```js
const API_TOKEN = 'MyKitchen-2026-tomato88';
```
- 只用英文、數字、`-`，越長越好。
- **記下來**，等一下網頁 App 要填一樣的。
- 為什麼需要？之後部署的網址任何人都能連，密碼可以防止別人亂寫入你的試算表。

### 步驟 1-5　儲存
按 **Ctrl+S**（Mac：⌘+S）或上方的 💾 圖示。左上角「未命名的專案」可以改名為 `Cook Again`。

### 步驟 1-6　執行 setup 並授權（第一次才需要）
1. 上方工具列有個函式下拉選單（在「執行」「偵錯」旁邊），選 **`setup`**。
2. 按 **▶ 執行**。
3. 跳出「需要授權」→ 按 **「審查權限」**。
4. 選擇你的 Google 帳號。
5. 會看到 **「Google 尚未驗證這個應用程式」** 的警告畫面 —— 這是正常的，因為這是你自己寫的程式，沒有送去給 Google 審核：
   - 點左下角的 **「進階」**（Advanced）
   - 點 **「前往「Cook Again」（不安全）」**
6. 看到權限清單（查看/管理試算表、雲端硬碟）→ 按 **「允許」**。
   - 新版畫面可能是一個個勾選框，請**全部勾選**再按「繼續」。
7. 下方「執行記錄」出現：
   ```
   ✅ 工作表：https://docs.google.com/spreadsheets/...
   ✅ 照片資料夾：https://drive.google.com/drive/folders/...
   ```
   就成功了！

✔️ **檢查點**：回到試算表，下方應該多了一個「料理紀錄」工作表，第一列有欄位標題；你的 Google 雲端硬碟也多了一個「Cook Again 料理照片」資料夾。

> 🔒 這些權限只授予「你自己的帳號執行你自己的程式」，資料不會傳給任何第三方。

### 步驟 1-7　部署成網頁應用程式（取得網址）
1. Apps Script 右上角點藍色的 **「部署」→「新增部署作業」**。
2. 點左邊「選取類型」旁的 **⚙️ 齒輪** → 選 **「網頁應用程式」**。
3. 填寫：
   | 欄位 | 要選/填的值 |
   |---|---|
   | 說明 | `v1`（隨意） |
   | 執行身分 | **我（你的 email）** |
   | 誰可以存取 | **所有人**（Anyone）⚠️ 不是「任何擁有 Google 帳戶的使用者」 |
4. 按 **「部署」**。
5. 畫面顯示「網頁應用程式」網址，長得像：
   ```
   https://script.google.com/macros/s/AKfycbx......很長一串....../exec
   ```
   按 **「複製」**，貼到記事本先存著。

> ❓「所有人」安全嗎？網址本身很長很難猜，加上必須知道你的密碼 (API_TOKEN) 才能讀寫。網址和密碼請不要公開貼出來。

## 第 2 部分：把網頁 App 放上網（GitHub Pages，約 5 分鐘）

### 步驟 2-1　把程式合併到 main 分支
程式目前在 `claude/peaceful-sagan-wwyhja` 分支。到 GitHub 專案頁面建立 Pull Request 並 Merge 到 `main`（或請 Claude 幫你開 PR）。

### 步驟 2-2　開啟 GitHub Pages
1. 打開 <https://github.com/samsongrace521/cook-again> → 上方 **Settings**。
2. 左側選單點 **Pages**。
3. 「Build and deployment」→ Source 選 **Deploy from a branch**。
4. Branch 選 **`main`**、資料夾選 **`/ (root)`** → 按 **Save**。
5. 等 1～2 分鐘，重新整理頁面，上方會顯示：
   ```
   Your site is live at https://samsongrace521.github.io/cook-again/
   ```

> ⚠️ 免費帳號的 GitHub Pages 需要 repo 是 **Public（公開）**。公開的只有程式碼，**你的料理資料和照片都在你的 Google 帳號裡，不會公開**，密碼也不在程式碼裡（只存在你的瀏覽器和 Apps Script）。

## 第 3 部分：在手機上連接（約 2 分鐘）

1. 用手機打開 `https://samsongrace521.github.io/cook-again/`
2. 點上方 **⚙️ 設定**。
3. 「Apps Script 網頁應用程式網址」貼上步驟 1-7 的網址（結尾是 `/exec`）。
4. 「密碼」填步驟 1-4 設定的 API_TOKEN。
5. 按 **🔌 測試連線** → 看到「✅ 連線成功！」。
6. 按 **儲存設定**。

### 加到手機主畫面（像 App 一樣使用）
- **iPhone（Safari）**：下方「分享」按鈕 ⬆️ →「加入主畫面」。
- **Android（Chrome）**：右上角 ⋮ →「加到主畫面」。

> 每台裝置（手機、平板、電腦）都要各自做一次第 3 部分的設定。

## 使用方式

| 情境 | 怎麼做 |
|---|---|
| 開始做菜 | 「✏️ 記錄」→ 填名稱、類別，邊做邊填步驟、拍過程照片（中途關掉也會自動保存草稿） |
| 做完了 | 拍成品照、打星星、寫心得、**問題/改進**、**下次調整** → 💾 儲存 |
| 想要文字版食譜 | 按「📝 產生文字食譜」或在紀錄詳情按「📋 複製文字」，可貼到 LINE、筆記 App |
| 再做同一道菜 | 「📚 我的料理」→ 該料理的「🔁 再做」，會帶入上次的食材和步驟，上方顯示上次的改進提醒 |
| 在表單輸入做過的菜名 | 自動跳出「上次的筆記」提醒，可一鍵帶入上次食譜 |
| 沒網路時 | 照常儲存，會暫存在手機；有網路後到「⚙️ 設定」→「⬆️ 全部上傳」 |

### 試算表欄位說明
| 欄位 | 內容 |
|---|---|
| 紀錄ID | 每筆紀錄的編號（不要改） |
| 料理名稱 / 類別 / 第幾次做 | 同名料理會自動算第幾次 |
| 評分 | ★★★☆☆ |
| 成品照片預覽 | 第一張成品照的縮圖 |
| 食材 / 步驟 / 成品心得 / 改進建議 / 下次調整 | 文字內容 |
| 文字食譜 | 完整的文字版食譜，可直接複製 |
| 照片資料夾 | 這次料理所有照片的雲端硬碟資料夾連結 |
| 原始資料JSON（隱藏欄） | App 讀取用的完整資料，**請不要修改或刪除** |

> 📌 App 是讀取「原始資料JSON」欄。如果你直接在試算表改文字，App 裡不會變；要修改請用 App 的「✏️ 編輯」。可以放心在試算表**新增別的工作表**做統計，但請不要改「料理紀錄」工作表的欄位順序。

## 修改 Apps Script 程式後要「發布新版本」⚠️

只按儲存**不會生效**！每次修改 `Code.gs`（包含改密碼）後：

1. **部署 → 管理部署作業**
2. 選你的部署 → 右上角 **✏️ 編輯（鉛筆圖示）**
3. 「版本」下拉選 **「新版本」**
4. 按 **部署**

這樣網址**不會變**，手機不用重新設定。（如果按的是「新增部署作業」，會產生新網址，就要回到第 3 部分重新填網址。）

## 常見問題排解

| 狀況 | 原因與解法 |
|---|---|
| 測試連線出現「連不上 Apps Script」 | ① 網址結尾要是 `/exec`，不是 `/dev`。② 部署時「誰可以存取」要選「**所有人**」。改設定請用上面「發布新版本」的方式，在編輯畫面調整存取權。 |
| 「Apps Script 回傳的不是資料」 | 通常是存取權選成「任何擁有 Google 帳戶的使用者」或「只有我自己」，同上改成「所有人」。 |
| 「密碼(API_TOKEN)不正確」 | App 設定的密碼和 Code.gs 不一樣。注意大小寫；若你改了 Code.gs，記得「發布新版本」。 |
| 「請從試算表的擴充功能建立此程式」 | 你是在 script.google.com 直接建立專案。請回到第 1 部分，從試算表的「擴充功能 → Apps Script」建立。 |
| 照片上傳了，但 App 裡顯示不出來 | 公司/學校的 Google Workspace 帳號常禁止「知道連結的人可檢視」。建議改用個人 Gmail 帳號；或點紀錄裡的「📁 照片資料夾」連結直接在雲端硬碟看。 |
| 上傳很慢 | 照片已自動壓縮到每張約 200KB，但一次很多張仍需要時間，請等按鈕恢復再離開。 |
| 想讓家人也能記錄 | 把 App 網址和密碼給他，他在自己手機做第 3 部分即可，資料會寫進同一份試算表。 |
| 不小心刪了紀錄 | 試算表「檔案 → 版本記錄」可以還原；照片刪除紀錄時不會刪掉。 |
| 用量限制 | 個人 Gmail 的 Apps Script 每天可執行數千次，雲端硬碟免費 15GB 約可放 5～7 萬張壓縮後的照片，一般使用不會碰到上限。 |

## 進階：沒有 GitHub Pages 也能用嗎？

可以。下載整個專案，用電腦瀏覽器直接打開 `index.html` 通常也能使用（設定只會存在那台電腦的瀏覽器裡；若測試連線失敗，請改用 GitHub Pages）。手機上使用還是建議用 GitHub Pages。
